- Marathi shares Devanagari with Hindi, so a Hindi word left in a Marathi line is invisible to a script check.
  Re-author every line, including word lists: a list of words to avoid is rebuilt for Marathi, not copied.
- A Marathi tester found the first Purple Dots Marathi bot "very complicated": write like a neighbour, not a
  form. Prefer दाखला / कागदं / मदत / तपासणी over प्रमाणपत्र / कागदपत्रे / सहाय्य / मूल्यमापन.
- Marathi ends a sentence with a full stop (.), not the Hindi danda (।).
- Check every name for its meaning in Marathi, including the bot's own persona name: in the demo, शिक्षा
  (education in Hindi) means punishment in Marathi; शिक्षण is education.
