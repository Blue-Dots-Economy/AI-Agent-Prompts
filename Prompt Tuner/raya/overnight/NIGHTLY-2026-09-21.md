## Harness defects (unchanged, still open)

1. **Sub-threshold calls graded PASS.** The header says "min 2 usable calls per bot", but
   `fleet_report.py` computes `verdict = "UNTESTED" if calls <= 0 else ("FAIL" if hits else "PASS")`
   — `a.min_calls` is printed and never used. `kkb-hi-in-signals` shows PASS on one call tonight.
   Flagged 09-13, 09-14, 09-16, 09-19, 09-20; still open.
2. **`call_count` does not page.** It reads `limit=100` with no offset loop, so a bot with more than
   100 listed calls is undercounted. It did not bite tonight (verified above) but it is the same
   code that produced the 09-18 miscount.
3. **Parity fetches are rate-limited.** `toolschema_parity.py` has no backoff; a 429 silently
   shrinks a family to one bot and still prints CLEAN. A family with fewer than 2 fetched bots
   should print NO COVERAGE, not CLEAN.
