## Harness defects found during this run

**1. `fleet_report.py` can show PASS below its own coverage threshold.** The header prints
"min 2 usable calls per bot" and the docstring says "at least MIN_CALLS usable calls in the window,
else UNTESTED", but the verdict at `raya/regression/fleet_report.py:151` is
`"UNTESTED" if calls <= 0 else ("FAIL" if hits else "PASS")` — it never compares against
`min_calls`. `maya-hi-signals` shows **PASS on a single call** tonight. This is the same shape as the
2026-09-04 defect: a bot that has not really been tested reads as a pass. A human should decide the
fix; flagged, not changed.

**2. `already_applied_rate` graded zero calls while the window contained two.** It printed
"no ACTION_LIMIT_REACHED calls in the cache", but `apply_outcomes` counted 2 `ACTION_LIMIT_REACHED`
failures in the same window. Its cache is stale — treat that detector as **NO COVERAGE** tonight,
not clean.

**3. Raya `GET /api/agent/{id}` returned empty `tools` intermittently**, needing up to 4 retries to
read tool schemas. The parity script has no retry; a flaky night could make it silently compare
nothing.
