  maya-hi-in-signals 911204413383.
- One tester DID (917946350285) = ONE call at a time. Bridge rate ~27%; it drops to 19% if you
  redial within 30-90s of the last call ending, 62% if the line has been idle >10 min.
- `contact_memory` sent via agent_args does NOT reach the model (proved by c2ffe9fb). Memory-gated
  preconditions cannot be set from the harness, and stored memory cannot be read back.
- Tester persona must be SHORT (~1000 chars, literal reply list) or it drifts into acting as the bot.
- Launch runners with Bash `run_in_background: true`, never nohup — nohup is invisible to the user.
- POST /api/call is a token bucket; two in the same second gets one 429.
