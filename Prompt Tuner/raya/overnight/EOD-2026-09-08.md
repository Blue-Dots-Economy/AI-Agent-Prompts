## Platform limit found 2026-09-09: tool descriptions cap at 1024 characters

`PATCH /api/agent/{id}` with a `tools` payload returns **400** with
`{"error":"Tool description is required and must be 1024 characters or fewer"}` when any
`llm_tools[].function.description` exceeds 1024 chars. The seeker bots' `apply_job` descriptions
already run at **968-988**, so there is only ~40 characters of headroom. A no-op PATCH of the same
`tools` object returns 200, so the cap is the only thing being enforced here.

`scripts/fix_applyjob_desc.py` computes the per-agent budget before sending and refuses to PATCH
anything that would exceed it. Any future edit to a tool description must do the same — the failure
mode is a bare 400 with no indication of which tool was too long.
